# شناسنامه ساختمان — دموی استاتیک

رابط فارسی و راست‌به‌چپ برای مشاهده مشخصات یک ساختمان پس از اسکن QR و پنل آزمایشی واحد کنترل نظارت. این پروژه از **Tailwind CSS 4، Alpine.js 3، Motion و Leaflet** استفاده می‌کند و هیچ دیتابیس یا سروری برای داده‌ها ندارد.

## اجرای سریع

خروجی آماده در پوشه `dist` قرار دارد. داخل پوشه اصلی پروژه، برای اجرا با سرور ساده:

```bash
python3 -m http.server 8081 --directory dist
```

سپس `http://localhost:8081` را باز کنید. اگر پورت اشغال بود، شماره دیگری انتخاب کنید. می‌توانید پوشه `dist` را روی هر هاست استاتیک، از جمله Replit یا Vercel، قرار دهید. بازکردن مستقیم فایل HTML ممکن است در بعضی مرورگرها دسترسی نقشه و ذخیره محلی را محدود کند؛ سرور ساده پیشنهاد می‌شود.

## امکانات

- رابط واکنش‌گرا، فونت محلی وزیرمتن، رنگ‌بندی روشن و نشان آپلودشده.
- نمایش تعداد طبقات، سطح اشغال، مساحت زمین و هر ۱۶ نقش درخواست‌شده.
- فیلتر عوامل بر اساس گروه و جستجوی نام یا تخصص.
- نقشه Leaflet دانشگاه شهید بهشتی تهران با پین قابل کلیک، نمایش آدرس، زوم، بازگشت به موقعیت و مسیریابی.
- جابه‌جایی با دو انگشت در نقشه داخل صفحه؛ اسکرول معمولی صفحه حفظ می‌شود. روی کامپیوتر، برای زوم با چرخ ماوس کلید Ctrl یا ⌘ را نگه دارید.
- نمای بزرگ نقشه با حرکت آزاد، کنترل‌های لمسی و بستن با کلید Escape؛ اندازه نقشه با تغییر ابعاد صفحه اصلاح می‌شود.
- نقشه از سرویس استاندارد OpenStreetMap بارگیری می‌شود؛ هیچ API Key یا ثبت‌نامی برای این نسخه نیاز نیست. پین سفارشی و سبک روشن حفظ شده‌اند.
- نمایش نقشه و مسیریابی به اینترنت نیاز دارند. هنگام قطع اتصال یا خطای سرویس، پیام روشن و دکمه تلاش مجدد نمایش داده می‌شود؛ با برگشت اینترنت، بارگیری خودکار دوباره انجام می‌شود.
- کد QR واقعی برای نشانی فعلی صفحه و کپی لینک.
- ورود بدون پیامک با هر شماره موبایل معتبر ایران؛ ارقام فارسی، عربی، انگلیسی و پیش‌شماره `+98` پشتیبانی می‌شوند.
- مشاهده گزارش‌های ناظرین و مجری، جواب آزمایشگاه بتن و خاک، نامه‌ها و دریافت نسخه متنی هر مدرک.
- ثبت گزارش، اعتبارسنجی فرم، ذخیره خودکار پیش‌نویس به تفکیک شماره موبایل، جستجو و فیلتر گزارش‌های من.
- نگهداری گزارش‌ها در `localStorage` همان مرورگر و باقی‌ماندن آن‌ها پس از تازه‌سازی.
- حالت کاهش حرکت مطابق تنظیمات سیستم، مسیرهای صفحه‌کلید و مدیریت فوکوس پنجره‌ها.

## ویرایش و ساخت مجدد

```bash
npm ci
npm run build
npm run check
```

| فایل | کاربرد |
| --- | --- |
| `dist/index.html` | ساختار صفحه و قالب‌های Alpine |
| `dist/assets/app.js` | داده‌های نمونه، فرم‌ها، ذخیره محلی و وضعیت پنجره‌ها |
| `dist/assets/project-map.js` | کنترل Leaflet، OpenStreetMap، خطای اتصال و تغییر اندازه |
| `src/styles.css` | Tailwind و سبک‌های اختصاصی |
| `dist/assets/building.svg` | تصویر شماتیک معماری |
| `dist/assets/logo.png` | تصویر اصلی لوگوی کارفرما |
| `scripts/build.mjs` | کامپایل Tailwind و قرار دادن وابستگی‌های محلی |
| `scripts/check.mjs` | بررسی جریان‌های اصلی دمو در DOM |

پس از تغییر کلاس‌ها یا سبک‌ها، `npm run build` را اجرا کنید. خروجی HTML، CSS، فونت و کتابخانه‌های JS به CDN وابسته نیستند.

## داده‌های نمونه

برای تغییر اسامی، نقش‌ها، گزارش‌ها، آزمایشگاه‌ها و نامه‌ها، آرایه‌های ابتدای `dist/assets/app.js` را ویرایش کنید. مشخصات عمومی ساختمان در `dist/index.html` قرار دارند. اطلاعات همه اشخاص و ساختمان فرضی است؛ دانشگاه صرفاً موقعیت نمونه نقشه است.

گزارش‌های جدید و پیش‌نویس‌ها فقط روی همان دستگاه، مرورگر و دامنه باقی می‌مانند. ورود این نسخه احراز هویت واقعی و محدودیت دسترسی امن ایجاد نمی‌کند. داده‌های بخش کارشناسی در سورس استاتیک موجودند. هنگام اتصال به بک‌اند، احراز هویت و کنترل دسترسی باید سمت سرور انجام شوند.

## وضعیت بررسی

جریان ورود، فیلترها، ثبت گزارش، بازیابی گزارش و پیش‌نویس و نمای مدارک با Alpine در DOM بررسی می‌شوند. بررسی نقشه با Leaflet واقعی شامل زوم، پین، بازگشت به موقعیت، تغییر اندازه، کنترل دو انگشتی، نمای بزرگ، خطای کامل و جزئی کاشی‌ها، اتصال مجدد و اطمینان از درخواست مستقیم OpenStreetMap بدون کلید است. خطاهای اتصال و ابعاد صفحه در این آزمون‌ها شبیه‌سازی می‌شوند. تصویر واقعی سرویس جدید نیز بازبینی شده است؛ بررسی کامل بصری در مرورگر و دستگاه واقعی در محیط ساخت انجام نشده است.
